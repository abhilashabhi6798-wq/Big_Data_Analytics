# Exercise 11: Apache Spark and PySpark Word Count

## Aim

To install and configure Apache Spark with PySpark and implement a Word Count program using Spark DataFrames.

## Objective

* To understand the basic working of Apache Spark.
* To use PySpark for distributed data processing.
* To create an RDD and convert it into a DataFrame.
* To split text into individual words.
* To count the frequency of each word.
* To perform Word Count on a text file.

## Technologies Used

* Apache Spark 4.1.1
* PySpark
* Python 3.12
* Java 21
* Ubuntu / WSL

## Files

* `word_count.py` - PySpark program for Word Count.
* `sample.txt` - Input text file used for the advanced task.
* `output.txt` - Output generated by the Spark program.

## Input Data

The main Word Count program uses the following input:

```text
Hello world Hello Spark
Spark is great for big data
Hello Python and Spark
```

## Program Execution

Run the PySpark program using:

```bash
spark-submit word_count.py
```

## Output

The main Word Count operation produces:

```text
+------+-----+
|  word|count|
+------+-----+
| Hello|    3|
| Spark|    3|
| world|    1|
|   for|    1|
| great|    1|
|    is|    1|
|  data|    1|
|   big|    1|
|   and|    1|
|Python|    1|
+------+-----+
```

## Advanced Task

The program also reads text from `sample.txt` using:

```python
spark.read.text("sample.txt")
```

Input:

```text
Hello Hadoop
```

Output:

```text
+------+-----+
|  word|count|
+------+-----+
| Hello|    1|
|Hadoop|    1|
+------+-----+
```

## Result

Apache Spark and PySpark were successfully configured, and the Word Count program was implemented using Spark DataFrames. The program successfully counted words from both manually created input data and an external text file.
