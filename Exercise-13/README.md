# Exercise-13: MongoDB and Neo4j NoSQL Database Lab

## Overview

This exercise demonstrates the installation, configuration, and hands-on implementation of two popular NoSQL databases:

- MongoDB (Document-Oriented Database)
- Neo4j (Graph Database)

The practical covers CRUD operations, aggregation, indexing, graph creation, relationship management, and Cypher queries using Ubuntu 24.04 (WSL).

---

## Aim

To install MongoDB and Neo4j and perform document-based and graph-based database operations using NoSQL technologies.

---

## Objectives

- Install MongoDB and Neo4j.
- Create and manage databases.
- Perform CRUD operations in MongoDB.
- Execute aggregation and indexing operations.
- Create nodes and relationships in Neo4j.
- Execute Cypher queries.
- Perform graph traversal, update, and delete operations.

---

## Technologies Used

- Ubuntu 24.04 LTS (WSL)
- MongoDB 8.0
- Neo4j Community Edition
- MongoDB Shell (mongosh)
- Cypher Query Language
