# Spark Exercise 10

Complex Event Processing using Apache Spark Structured Streaming.

## Tasks Performed

- Processed event data using Spark Structured Streaming
- Defined a schema for streaming events
- Applied event-time window operations
- Used watermarking for streaming data
- Performed window-based event aggregation
- Detected login followed by purchase event patterns
- Implemented rule-based complex transaction detection

## Technologies Used

- Apache Spark
- PySpark
- Spark Structured Streaming
- Python
